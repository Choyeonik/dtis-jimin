# 05. 정책 문서

> 크롬 확장프로그램 — 군 장병 대상 열차 승차권(좌석) 취소표 자동 신청
> (사용 범위, 운영, 리스크 관리 등 프로젝트 전반의 정책을 정의)

## 1. 사용 범위 정책

- 사용자는 본인 한 명뿐이다. 여러 사용자를 위한 계정 분리, 다중 사용자 지원 등은 고려하지 않는다.
- 크롬 웹스토어에는 배포하지 않는다. 본인 PC에 개발자 모드로 직접 설치해서 사용한다(Chrome Web Store 심사 정책을 따를 필요는 없음).

## 2. 계정/보안 정책

- 로그인은 자동화하지 않는다 — 사용자가 미리 직접 로그인해두고, 그 상태에서 확장프로그램을 실행한다(아이디/비밀번호를 코드나 저장소에 저장하지 않음).

## 3. 자동화 운영 정책

- 새로고침 간격은 260~300ms 사이 난수로 고정한다(임의로 더 빠르게 조정하지 않음).
- 정각(오픈 시각) 자동 시작 기능은 두지 않는다 — 사용자가 직접 "시작" 버튼을 눌러 실행한다.
- 자동화 실행 중에는 PC가 절전 모드로 들어가지 않도록 막는다.
- 한 번 시작하면 등록된 슬롯(최대 2개)의 신청이 모두 끝나거나, 사용자가 직접 "중지"를 누르거나, 대상 탭이 이동/종료될 때까지 계속 실행된다.

## 4. 리스크 관리 정책

- 이 자동화(빠른 새로고침 반복)로 인해 계정이 일시 정지되거나 제재를 받을 가능성은 감수하고 사용한다. 별도의 "일정 시간/횟수 이상 실패 시 자동 중단" 안전장치는 두지 않는다(사용자가 직접 "중지" 버튼으로 멈출 수 있는 것으로 충분하다고 판단).

## 5. 코드/저장소 관리 정책

- GitHub 저장소는 **비공개(private)**로 운영한다 — 다른 사람이 코드를 보고 그대로 가져다 쓰거나, 군 관련 자동화 도구라는 점이 알려지는 것을 방지하기 위함.
- 디스코드 웹훅 URL, 카카오 API 토큰 등 민감한 값은 `.gitignore`로 제외한 별도 설정 파일에 보관한다(03-requirements.md 참고).

## 6. 미해결 질문 / 제안

- 현재까지 남은 미해결 항목 없음.

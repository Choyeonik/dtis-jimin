## F1. 신청 대상 슬롯 설정 및 조회 자동 실행

- 출발역/도착역 입력 방식: 사이트에 있는 것과 동일한 드롭다운(선택 목록) 형태로 만든다(자유 텍스트 입력 아님).
- 목록 소스: 코드에 고정해서 넣지 않고, 실제 사이트 페이지에서 그 순간의 역 목록을 읽어와 사이드 패널 드롭다운에 반영한다(사이트가 목록을 바꿔도 항상 최신 상태 유지).
- 슬롯 입력 항목 추가: 날짜, 출발역, 도착역에 더해 **오전/오후** 선택도 추가한다(같은 출발역/도착역의 열차가 여러 개일 때 시간대를 좁히기 위함).
- 읽어오는 시점: 사용자가 사이트 페이지를 미리 열어둔 상태에서 사이드 패널의 "역 목록 읽어오기" 버튼을 누르면, 그 열려있는 페이지에서 목록을 읽어와 드롭다운에 채운다(패널을 여는 즉시 자동으로 읽어오지는 않음).

**화면 구성 정리** (구현 시 참고):

- **화면A "탑승신청" 페이지**: 상단에 "< 이전" 버튼과 홈 아이콘, "열차현황 정보" 섹션에 탑승일자 입력(`<input type="date">`) + "조회" 버튼이 있고, 그 아래에 조회 결과 테이블(번호/신청여부/잔여석/일자/열차명/출발역/도착역)이 표시된다. 날짜 입력과 결과 테이블이 한 화면에 같이 있다.
- **화면B "안내" 팝업**: 화면A에서 원하는 행의 "예약가능"을 클릭하면 뜨는 이용 안내 문구 페이지. "확인" 버튼만 있다.
- **화면C "잔여석예약" 화면**: 화면B에서 확인을 누르면 진입. 탑승일자/노선명/차종/열차명(자동 표시), 승차역/하차역(드롭다운), 그 안에 별도의 "잔여석예약" 표(선택 버튼/호차/좌석/출발역/도착역), 그리고 "새로고침"/"좌석신청" 버튼이 있다.

## F2. 조회 실행 (화면A)

- 화면A의 날짜 입력 폼에 슬롯의 날짜를 채우고 "조회" 버튼을 자동으로 클릭한다 → 같은 화면(화면A)의 결과 테이블이 채워진다.

## F3. 조건에 맞는 행 매칭 및 선택 (화면A)

- 화면A의 결과 테이블에서, 슬롯에 설정된 출발역·도착역과 일치하고 출발 시각이 지정된 오전/오후에 해당하는 행을 찾는다.
- 조건에 맞는 행이 여러 개면 그중 아무거나 하나를 고른다.
- 조건에 맞는 행이 하나도 없으면(드문 경우로 예상됨) 사이드 패널에 경고 문구를 띄운다.
- 찾은 행의 "예약가능" 버튼을 클릭해 화면B로 진입한다.

## F4. 중간 안내 팝업 확인 (화면B)

- 화면B의 "확인" 버튼을 자동으로 클릭해 화면C로 넘어간다.

## F5. 승차역/하차역 선택 (화면C)

- 화면C 상단에는 탑승일자/노선명/차종/열차명이 이미 자동으로 채워져 있음(화면A에서 고른 행 기준).
- "승차역"/"하차역" 드롭다운에 슬롯에 입력해둔 출발역/도착역과 같은 값을 선택한다.

## F6. 새로고침 반복 및 좌석 신청 (화면C)

- 화면C 안에는 "잔여석예약"이라는 별도의 표가 있고, 컬럼은 선택(버튼)/호차/좌석/출발역/도착역이다.
- 평소에는 이 표에 행이 하나도 없음(빈 상태) — 이때는 화면 안의 "새로고침" 버튼을 계속 눌러야 한다(260~300ms 사이 난수 간격, F5나 브라우저 리로드가 아님).
- 새로고침하다가 이 표에 행(좌석)이 하나라도 뜨면, 여러 개 중 아무거나 하나 골라 "선택" 버튼을 클릭한다 → 그 좌석의 호차/좌석 값이 위쪽 폼(호차/좌석 입력칸)에 자동으로 채워진다.
- 이어서 "좌석신청" 버튼을 클릭하고, 브라우저 기본 확인(confirm) 대화상자가 뜨면 "확인"을 누른다.

## F7. 실패 감지 및 재시도 (화면C)

- confirm에서 "확인"을 누른 뒤 "다른 사람이 먼저 선택했습니다" 같은 alert가 뜨면 신청 실패다.
- 실패해도 화면은 그대로 화면C에 남아있으므로, 화면 이동 없이 F6(새로고침 반복)부터 곧바로 다시 시도한다.

## F8. 슬롯 전환 (다음 날짜로 이동)

- 첫 번째 슬롯의 신청이 성공하면, 화면C에서 "이전" 버튼을 **2번** 클릭해 화면A(탑승신청 페이지, 날짜 입력+조회)로 돌아간다.
- 두 번째 슬롯의 날짜/출발역/도착역/오전·오후 값으로 F2~F7을 동일하게 반복한다.
- 등록된 모든 슬롯의 신청이 끝나면 자동화가 종료된다.

## F9. 완료/중단 알림

- 슬롯 신청이 성공하면 디스코드 웹훅 + 카카오톡 나에게 보내기로 완료 알림을 동시에 보낸다.
- 대상 탭이 이동/종료되어 자동화가 중단될 때도(F10) 동일한 두 채널로 알린다.

## F10. 탭 이탈 감지 및 자동 중단

- 자동화 중 대상 탭이 다른 페이지로 이동되거나 닫히면 즉시 자동화를 중단하고 F9의 알림을 보낸다.

## F11. 시작/중지 제어

- 사이드 패널(Chrome Side Panel)에 "시작"/"중지" 버튼을 두어 사용자가 자동화를 직접 시작·중단할 수 있다.
- 실행 중에는 "실행 중" 상태만 표시한다(상세 로그, 시도 횟수 등은 표시하지 않음).
- 자동화 실행 중 사이드 패널을 닫았다가 다시 열어도 입력값과 진행 상황은 유지된다(확장/브라우저 재시작 시에만 초기화).

## F12. 절전 방지

- 자동화 실행 중에는 `chrome.power` API로 PC가 절전 모드에 들어가지 않도록 막는다.

## 미해결 질문 / 제안

- [제안] 사용자가 사이트 페이지를 열어두지 않은 상태에서 "역 목록 읽어오기"를 누르면 어떻게 될지 정해야 함 — 예: "사이트 페이지를 먼저 열어주세요" 안내 메시지를 보여주는 정도로 처리.
